# labops-shortlist — Шорт-лист: от вакансии к ранжированному списку кандидатов

Опиши вакансию — получишь профиль кандидата, поисковые запросы и ссылки с фильтрами
для hh.ru, SuperJob, Habr Career и Зарплата.ру. Когда отберёшь резюме под своим аккаунтом
и загрузишь их — капсула разберёт каждое: «Да / Подумать / Нет» с причиной и вопросами
для звонка.

**Что получаешь:**
- Профиль кандидата: обязательные и желательные навыки, стоп-факторы.
- Готовые поисковые запросы (boolean search) и ссылки для работных сайтов.
- Таблица оценки резюме: «Да / Подумать / Нет» + причина + вопросы для звонка.
- HTML-шорт-лист для хранения и показа.

Есть отклики? Напиши «У меня уже есть отклики» — сразу к оценке резюме.

## Как поставить

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-shortlist
/plugin install shortlist@labopsai-shortlist
```

Напиши: **«Шорт-лист»**.

### Claude (claude.ai, приложение)

1. Настройки → Коннекторы и плагины → Маркетплейс.
2. Вставь ссылку: `https://github.com/DianaMarshrut/labops-shortlist`
3. Установи плагин «shortlist».
4. Напиши: **«Шорт-лист»**.

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-shortlist
```

Через `/plugins` → Install → напиши: **«Шорт-лист»**.

### ChatGPT (через проект)

1. Создай проект «Шорт-лист» в ChatGPT.
2. Загрузи файл `chat-instruction.md` в файлы проекта.
3. Напиши: **«Шорт-лист»**.

## Откуда берём резюме

| Вариант | Как работает |
|---|---|
| Файлы в чате (PDF/Word) | Загружай по одному или пачкой; большую пачку — частями [проверить лимит] |
| Google Диск | Коннектор Google Drive в настройках чата (гайд: guides.labopsai.pro/google-workspace-claude) |
| Яндекс Диск | Скачай файлы и загрузи в чат [проверить MCP] |
| Текстом | Скопируй текст резюме в чат |

## Поиск кандидатов

Капсула даёт поисковые запросы и ссылки с фильтрами — ты используешь их под своим
аккаунтом работодателя на выбранном сайте. Поиск в базе резюме (hh.ru, SuperJob и др.)
требует аккаунта работодателя на этих платформах.

[проверить: точные параметры URL фильтров для hh.ru, SuperJob, Habr Career — Пабло уточнит]

## Ограничения

- Оценка ведётся только по опыту и навыкам — контакты кандидатов не используются.
- Поиск в закрытых базах резюме требует аккаунта работодателя — капсула не заменяет его.
- Большая пачка резюме: загружай частями [проверить точный лимит].

## Команды

| Команда | Что делает |
|---|---|
| `Шорт-лист` | Начать: вопросы о вакансии → поиск → оценка |
| `У меня уже есть отклики` | Сразу к оценке резюме |
| `Добавь кандидата` | Оценить ещё одно резюме по тем же критериям |
| `Вопросы для звонка с [имя]` | Уточнить вопросы для конкретного кандидата |
